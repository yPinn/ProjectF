# 編輯成員資料

[回編輯首頁](../../README.md) · [更新圖片與語音](assets.md) · [儲存與確認發布](publish.md)

## 修改現有成員

1. 在 GitHub 開啟 [src/data/people.json](../../src/data/people.json)，按檔案右上方的 **鉛筆圖示（Edit this file）**。
2. 用編輯器的搜尋功能找該成員的 Twitch 登入帳號，例如 `winsyi`。每位成員的資料是一組 `{` 到 `}`；只改這一組。
3. 依下表修改冒號右邊的內容，完成後按 [儲存步驟](publish.md) 提交。

| 畫面上要改的內容 | 找這個欄位       | 如何填寫                                                                                                      |
| ---------------- | ---------------- | ------------------------------------------------------------------------------------------------------------- |
| 稱號             | `title`          | 例如 `"法克娛樂 副會長"`。                                                                                    |
| 介紹文字         | `bio`            | 建議 **120–180 字**；需要較完整介紹時可寫 **180–220 字**。超過 220 字會省略，標點、英文字母與中間空白也計入。 |
| 主題色           | `color`          | 填 `#` 加六位英數色碼，例如 `"#F0DD48"`；不填「黃色」等文字。                                                 |
| 遊戲圖示         | `tags`           | 例如 `["Valorant", "ETS2"]`，名稱須與下表完全一致，最多顯示前四個受支援項目。                                 |
| 照片、語音       | `photo`、`audio` | 依 [圖片與語音步驟](assets.md) 填寫。                                                                         |

例如，要把副會長改成主持人，只把 `"title": "法克娛樂 副會長"` 改成 `"title": "法克娛樂 主持人"`。

**保留欄位名稱、雙引號、逗號與括號。** 文字內需要引號時，使用「」；不要直接插入英文雙引號或換行。`section` 固定保留 `"slider"`。

不在表內的名稱不會出現圖示；新增種類請交由工程人員處理。

## 修改 CONTACT 聯絡網址

1. 開啟 [src/data/links.json](../../src/data/links.json)，按鉛筆圖示。
2. 在 `discord` 裡找到該成員帳號，只換冒號右邊的網址，例如 `"winsyi": "https://discord.gg/邀請碼"`。網址須以 `https://` 開頭。
3. 沒有帳號那一行時，可在 `discord` 的 `{` 後另起一行加入；新行末尾加逗號，接回原有資料。若裡面原本是空的、只有這一行，就不加逗號。沒有聯絡網址可不新增，或把網址填成 `""`。
4. [儲存並確認](publish.md)。帳號須與 `people.json` 的 `username` 完全相同。

## 管理成員名單

### 新增一位成員

1. 開啟 [people.json](../../src/data/people.json) 的編輯畫面，在最上方 `[` 後、原本第一位成員的 `{` 前插入下方整組資料。
2. 將 `your_login` 換成該成員的 Twitch 登入帳號。例：頻道網址是 `https://www.twitch.tv/winsyi`，帳號就填 `winsyi`，不用加 `@`。
3. 修改稱號、色碼、介紹及遊戲；**在這組最後的 `}` 後加一個逗號，變成 `},`**，才會接到原有第一位成員。
4. 先保持 `photo`、`audio` 為 `null` 並儲存；照片會暫用品牌圖、語音停用。再依 [素材步驟](assets.md) 上傳並填入路徑，需要 CONTACT 時依上節新增。

```json
{
  "username": "your_login",
  "photo": null,
  "section": "slider",
  "title": "法克娛樂 成員",
  "color": "#9DBFB0",
  "bio": "在這裡填寫成員介紹。",
  "tags": ["Valorant"],
  "audio": null
}
```

帳號只能填小寫英文字母、數字與底線，1–25 字，不可與現有成員重複。`null` 代表尚未提供，**不要加雙引號**。新增在最前面會第一個出現，可再依下一節調整。

### 調整展示順序

`people.json` 從上到下就是展示順序。移動該成員完整的 `{ … }` 到目標位置；**成員之間保留一個逗號，最後一位的 `}` 後不要加逗號**。不要只移動 `username` 那一行。

### 更換 Twitch 帳號

1. 改 `people.json` 的 `username`，再到 `links.json` 把該成員的舊帳號改成新帳號；若原本沒有那一行則不必新增。
2. 照片與語音檔名可以保留，無須跟著改名。畫面名稱取自 Twitch，不在此另外填寫；直播與 Clip 會依新帳號取得。
3. 完成兩份檔案的儲存後，再檢查 [最後一筆發布結果](publish.md)。

### 移除成員

1. 在 `people.json` 刪除該成員完整的 `{ … }`。刪中間成員時連同它後面的逗號刪除；刪最後一位時也移除前一位結尾的逗號。至少保留一位成員。
2. `links.json` 若有該帳號，也刪除對應一行，注意最後一行不能以逗號結尾。
3. 先 [儲存並確認畫面](publish.md)。原圖與語音可暫時保留，後續確認無人共用後再請工程人員清理。
